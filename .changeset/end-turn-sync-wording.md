End-turn remediation no longer tells an agent to commit and push when the only problem is that its checkout is behind work another session pushed. A project can name its safe catch-up command with `agents.gitSyncCommand`, and the message then names it. `artifacts delivery-card` now explains that the artifact folder itself is already on the card when a delivery path names it, instead of saying the path escapes the folder.
