browse checks: three false-positive fixes learned from one QA session. The runt gate skips a lone token hosted by a padded, boxed inline element (a code chip, pill, or badge is a UI control, not a prose word — it cannot be rebalanced by rewording, tag rows legitimately wrap to a single chip, and its shifted glyph box buckets as a phantom line beside normal text). The crowd gate excludes code-family tags (CODE, KBD, SAMP, VAR, OUTPUT) from panel classification — a flex/grid tag row blockifies their computed display, which defeated the inline-display exclusion and made bordered chips read as crowded cards. The critique rubric now tells the vision model that content cropped by a tile's own top/bottom slice boundary is a tiling artifact, not a defect — boundary crops were surfacing as spurious findings up to high severity, and their noise camouflaged real clipping reports.
