Claude Desktop stores its Claude Code sidebar separately for each signed-in
account. Switching accounts can make existing sessions disappear from the
sidebar even though their transcripts still exist.

`harn claude-desktop` can mirror those sidebar entries across accounts.

## Before you begin

- Run the command on the machine where Claude Desktop stores its session index.
- Fully quit Claude Desktop before relying on a changed sidebar. Closing the
  window usually leaves the app running in the system tray.

## Keep sessions visible after an account switch

<Steps>
1. Inspect the account directories Harnery found.

   ```bash
   harn claude-desktop accounts
   harn claude-desktop sessions
   ```

2. Preview the mirror plan. The command changes nothing without `--yes`.

   ```bash
   harn claude-desktop mirror --all
   ```

3. Apply the plan.

   ```bash
   harn claude-desktop mirror --all --yes
   ```

   Use `--to <account-prefix>` or `--from <account-prefix>` when you want a
   one-way copy. Use `--session <id-or-title>` to mirror one session.

4. Fully quit Claude Desktop and relaunch it.
</Steps>

Mirroring copies sidebar entry files. It does not copy or fork the transcript.
Both accounts point to the same underlying Claude Code session, so do not open
and drive that session from two accounts at the same time.

## Archiving availability

The former `tidy` subcommand was removed during the event-ledger migration.
Harnery currently has no command to archive Claude Desktop entries. Declaring
a task `done` records its lifecycle without archiving its sidebar entry.

## Troubleshooting

### No desktop data directory was found

Pass the directory explicitly:

```bash
harn claude-desktop accounts --data-dir <path>
```

Harnery normally checks `~/Library/Application Support/Claude` on macOS,
`%APPDATA%\\Claude` on Windows, and `~/.config/Claude` on Linux. A CLI running
under WSL also scans Windows user profiles mounted under `/mnt/c/Users/`.

### The sidebar did not change

Quit the Claude Desktop process from its tray menu, then relaunch it. The window
close button may only hide the application.
